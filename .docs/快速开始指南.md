## 🚀 快速初始化项目

按照以下步骤快速搭建项目环境。

---

## 📋 前置要求

- **Node.js**: 20.x LTS
- **pnpm**: 9.x
- **Git**: 最新版本

检查环境：

```bash
node --version   # v20.x.x
pnpm --version   # 9.x.x
git --version    # 2.x.x
```

安装 pnpm（如未安装）：

```bash
npm install -g pnpm
```

---

## 1️⃣ 创建 Next.js 项目

```bash
# 使用 pnpm 创建 Next.js 项目
pnpm create next-app@latest x-product-roadmap

# 配置选项（按以下选择）
✔ Would you like to use TypeScript? … Yes
✔ Would you like to use ESLint? … Yes
✔ Would you like to use Tailwind CSS? … Yes
✔ Would you like your code inside a `src/` directory? … Yes
✔ Would you like to use App Router? … Yes
✔ Would you like to customize the import alias (@/* by default)? … No
```

进入项目目录：

```bash
cd x-product-roadmap
```

## 3️⃣ 初始化 shadcn/ui

运行 shadcn/ui CLI：

```bash
pnpm dlx shadcn@latest init
```

选择以下配置：

```
✔ Which style would you like to use? › New York
✔ Which color would you like to use as base color? › Slate
✔ Would you like to use CSS variables for colors? › yes
```

添加常用组件：

```bash
# 一次性添加所有需要的组件
pnpm dlx shadcn@latest add button input textarea label card toast alert badge progress dialog sheet popover tooltip tabs dropdown-menu select checkbox radio-group switch table separator scroll-area avatar
```

### src/components/providers/theme-provider.tsx

'use client';

import { ThemeProvider as NextThemesProvider } from 'next-themes';

export function ThemeProvider({
  children,

## 🐛 常见问题

### Q: pnpm 安装依赖很慢？

A: 使用国内镜像：

```bash
pnpm config set registry https://registry.npmmirror.com
```

### Q: shadcn/ui 组件无法导入？

A: 检查 `tsconfig.json` 中的路径别名配置是否正确。

### Q: 暗色模式不生效？

A: 确保已安装 `next-themes` 并正确配置 `ThemeProvider`。
