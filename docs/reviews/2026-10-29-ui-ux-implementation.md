## 接口及兼容性

- 新增 POST /api/products/sample，成功返回 `{ success: true, id }`。ID 先分配，实体和导入证据在同一数据库事务中写入；中途写入失败整体回滚，序列允许留空号。
- 当前宪法新增可选 rule_sources，键为类别与规则 ID，值为引入该有效版本的 ADR ID；来源与规则使用同一账本顺序折叠，删除规则同时删除来源。
- Product、UserActivity、UserTask、UserStory 的深树输出增加 provenance；请求沿用现有接口字段约定。
- 详情、主要搜索和任务视图使用 URL 参数，保留既有路由。
- 沿用现有单实体状态 API 汇总批量结果；状态历史只读，纠正状态须真实更新实体，不再提供伪造历史的撤销动作。
- 四阶段 UX 优化本身无新增数据库列或迁移，无新增运行时依赖。此前 ADR 评审实现包含幂等迁移 0010（revises、评审事件与索引），交付时一并包含。保留一个 xartifact token 真源。
