- **common.ts**: 枚举类型（Priority, TaskPriority, TaskType, TaskStatus, LLMProvider）
- **project.ts**: Project, ProjectMetadata, ProjectSettings
- **user-journey.ts**: UserJourney, CreateUserJourneyDTO
- **user-story.ts**: UserStory, UserStoryForm, CreateUserStoryDTO
- **task.ts**: Task, CreateTaskDTO, UpdateTaskDTO

### 6. 基础工具函数 ✅

- **format.ts**: 日期格式化、工时格式化
- **id-generator.ts**: ID 生成函数（项目、旅程、故事、任务）
- **lib/utils.ts**: className 合并函数（cn）

### 7. 常量配置 ✅

- **routes.ts**: 路由常量
- **priorities.ts**: 优先级标签和颜色配置

### 8. 首页展示 ✅

- 简洁的首页布局
- 三个特性卡片展示
- 使用 shadcn/ui 组件（Button, Card）

## 🎯 下一步开发建议

### 阶段 1：实现核心工具库

1. **LLM 集成** (`src/lib/llm/`)
   - 创建 LLM 客户端封装
   - 实现 Prompt 模板系统
   - 支持 OpenAI 和 Anthropic

2. **TOML 解析** (`src/lib/toml/`)
   - 实现 TOML 序列化和反序列化
   - 添加格式验证

3. **数据持久化** (`src/lib/storage/`)
   - 实现 localStorage 封装
   - 实现 API 密钥加密

4. **数据验证** (`src/lib/validation/`)
   - 使用 Zod 创建验证 schemas

### 阶段 2：实现功能模块

**优先级顺序**:

1. **Projects** (项目管理) - 最基础
2. **Requirements** (需求分析) - AI 核心功能
3. **User Journeys** (用户旅程) - 数据组织
4. **User Stories** (用户故事) - CRUD 操作
5. **Story Map** (故事地图) - 可视化
6. **Tasks** (任务拆解) - AI 辅助
7. **Export** (导出功能) - 数据输出
8. **Settings** (系统设置) - 配置管理
9. **Onboarding** (用户引导) - 用户体验

### 阶段 3：优化和部署

1. 性能优化
2. 错误处理完善
3. 部署配置（Vercel/Netlify）
