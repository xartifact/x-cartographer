# Specification: 故事地图拖拽视觉反馈改进

## Feature Description

用户在故事地图画布上拖拽故事卡片时，当前的视觉反馈是一条横线指示器（DropInsertLine），仅标示插入位置。这种反馈不够直观——用户无法预见拖拽完成后卡片的最终排列效果。

本特性将拖拽视觉反馈从"横线指示插入位置"升级为"实时预览最终布局"：拖拽过程中，目标列的其他卡片实时让位（平滑移动到预期的最终位置），被拖拽卡片的目标位置显示一个半透明的"幽灵卡片"预览。用户可以在松手前就清楚看到放置后的完整布局效果。

## User Scenarios

### Scenario 1: 同旅程内重新排序

**Given** 一个旅程下有 3 张故事卡片 A、B、C
**When** 用户拖拽卡片 A 到卡片 B 和 C 之间
**Then** 卡片 C 平滑向下移动腾出空间，目标位置显示 A 的半透明预览，松手后 A 插入到 B 和 C 之间

### Scenario 2: 跨旅程移动

**Given** 旅程 1 有卡片 A、B，旅程 2 有卡片 C、D
**When** 用户拖拽卡片 A 到旅程 2 的卡片 C 之前
**Then** 旅程 2 的卡片 C、D 平滑向下移动，目标位置显示 A 的半透明预览，旅程 1 的卡片 B 向上移动填补空缺

### Scenario 3: 拖拽到空旅程

**Given** 旅程 1 有卡片 A，旅程 2 没有卡片
**When** 用户拖拽卡片 A 到旅程 2
**Then** 旅程 2 显示列高亮和 A 的半透明预览，松手后 A 移入旅程 2

### Scenario 4: 拖拽过程中切换目标位置

**Given** 用户正在拖拽一张卡片
**When** 用户将卡片在不同旅程和位置间移动
**Then** 每次目标位置变化时，所有受影响的卡片平滑过渡到新的预期位置

## Functional Requirements

- **FR-001**: 拖拽故事卡片时，目标插入位置 MUST 显示一个半透明的"幽灵卡片"预览节点，而非横线指示器
- **FR-002**: 拖拽过程中，目标列中位于插入位置之后的故事卡片 MUST 向下移动一个行高度（ROW_HEIGHT），腾出空间
- **FR-003**: 拖拽过程中，源列（如果与目标列不同）中被拖拽卡片之后的故事卡片 SHOULD 向上移动填补空缺
- **FR-004**: 卡片位置变化 SHOULD 有平滑的过渡动画效果
- **FR-005**: 列高亮指示器（DropColumnIndicator）MUST 保留不变
- **FR-006**: 横线指示器（DropInsertLine）MUST 被移除
- **FR-007**: 拖拽结束后的实际排序逻辑 MUST 保持不变，仅改变视觉反馈

## Success Criteria

- **SC-001**: 拖拽时目标位置出现半透明幽灵卡片，而非横线
- **SC-002**: 目标列的卡片在拖拽时实时让位，松手后保持在正确位置
- **SC-003**: 拖拽取消（Escape 或拖回原位）时，所有卡片回到原始位置
- **SC-004**: 无性能回退——拖拽交互保持流畅，无明显卡顿
- **SC-005**: 现有的拖拽排序功能完全正常，不引入回归

## Key Entities

- 幽灵卡片（Ghost Node）
- 故事节点（Story Node）
- 旅程列（Journey Column）
- 拖拽状态（Drag State）

## Edge Cases

- 拖拽卡片到当前位置的正上方或正下方（相邻位置交换）
- 拖拽到旅程的第一个位置或最后一个位置
- 快速连续拖拽（动画未完成时开始新拖拽）
- 旅程只有一张卡片时拖走该卡片
